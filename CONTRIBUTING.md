# Contributing to Polly-TS

Thank you for considering contributing to Polly-TS! We welcome contributions of all kinds, including bug fixes, new features, documentation improvements, and more.

## Getting Started

1. **Fork the Repository**
   - Navigate to the [Polly-TS GitHub repository](https://github.com/jbt95/polly-ts) and click the "Fork" button.

2. **Clone Your Fork**
   - Clone your forked repository to your local machine:
     ```bash
     git clone https://github.com/jbt95/polly-ts.git
     cd polly-ts
     ```

3. **Install Dependencies**
   - Install the required dependencies using `pnpm`:
     ```bash
     pnpm install
     ```

4. **Build the Project**
   - Build all packages to ensure everything compiles correctly:
     ```bash
     pnpm build
     ```

5. **Run Tests**
   - Verify that all tests pass:
     ```bash
     pnpm test
     ```

## Making Changes

1. **Create a Branch**
   - Create a new branch for your changes:
     ```bash
     git checkout -b feature/your-feature-name
     ```

2. **Make Your Changes**
   - Implement your changes in the appropriate files. Ensure your code follows the project's coding standards.

3. **Write Tests**
   - Add tests for your changes to ensure they work as expected and do not break existing functionality.

4. **Run Linter**
   - Check your code for linting errors:
     ```bash
     pnpm lint
     ```

5. **Commit Your Changes**
   - Commit your changes with a clear and concise commit message:
     ```bash
     git add .
     git commit -m "feat: add new feature"
     ```

## Submitting Your Contribution

1. **Push Your Branch**
   - Push your branch to your forked repository:
     ```bash
     git push origin feature/your-feature-name
     ```

2. **Open a Pull Request**
   - Navigate to the original Polly-TS repository and open a pull request from your branch. Provide a clear description of your changes and link any related issues.

## Code of Conduct

Please note that this project is governed by a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to abide by its terms.

## Need Help?

If you have any questions or need assistance, feel free to open an issue or start a discussion in the repository. We're here to help!

Thank you for contributing to Polly-TS!
